# Sakshi Dhiman — Portfolio

Responsive portfolio website for Sakshi Dhiman, built with semantic HTML and CSS.

## Live site

Once GitHub Pages is enabled, the portfolio will be available at:

https://sak5h1.github.io/Portfolio/

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the site on every push to
`main`. For the first deployment, open the repository's **Settings → Pages**,
choose **GitHub Actions** as the build and deployment source, and push to `main`
or run the **Deploy portfolio to GitHub Pages** workflow from the Actions tab.
If an earlier run failed before Pages was enabled, open the Actions tab and run
the workflow again after saving the Pages setting.
