# Sakshi Dhiman — Portfolio

Responsive portfolio website for Sakshi Dhiman, built with semantic HTML and CSS.

## Live site

Once GitHub Pages is enabled, the portfolio will be available at:

https://sak5h1.github.io/Portfolio/

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the site on every push to
`main`. GitHub Pages must first be enabled by a repository administrator: open
**Settings → Pages**, set the build and deployment source to **GitHub Actions**,
and save. GitHub does not allow this workflow to change repository Pages
settings. After enabling it, run **Deploy portfolio to GitHub Pages** from the
Actions tab or push to `main`.
